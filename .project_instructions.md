# SkillVane IT Academy LMS

## Overview
Learning Management System for SkillVane IT Academy selling GCP Data Engineering courses with Razorpay payment integration.

## Tech Stack
- Database: PostgreSQL with Prisma ORM
- Auth: NextAuth.js v4 with credentials provider (email/password)
- Payments: Razorpay (test mode, keys in .env)
- UI: Tailwind CSS, Radix UI, Framer Motion, Lucide icons

## Color Scheme
- Primary: Blue (HSL 230 80% 55%) - professional IT academy feel
- Default light theme

## Key Features
1. **Public pages**: Homepage, Courses listing, Course detail, About, Contact
2. **Auth**: Student signup/login, Admin role support
3. **Student Dashboard**: Enrolled courses, topic-wise video access via Google Drive links
4. **Admin Panel**: Course CRUD, topic/video management, student list, transaction history
5. **Payments**: Razorpay integration for course purchases, auto-enrollment on payment success

## Data Models
- User (STUDENT/ADMIN roles)
- Course (LIVE_BATCH/RECORDINGS/SELF_PACED/PROJECT types)
- CourseTopic (video URL, notes URL per topic)
- Enrollment (user-course mapping)
- Payment (Razorpay order tracking)

## Courses Seeded

2. GCP Data Engineering Course - Recordings (₹6,000)
3. Python for Data Engineering (₹599)
4. Health Care GCP Project (₹1,499)

## Route Structure
- `(public)/` - Public layout with header/footer
- `/dashboard/` - Student dashboard with enrolled courses
- `/dashboard/course/[id]` - Course content access (topic-wise videos)
- `/admin/` - Admin panel (courses, students, transactions tabs)
- `/admin/courses/[id]` - Topic management per course

## Admin Instructions
- Admin can add/edit/delete courses via the admin panel
- Topics with Google Drive video links are managed per course
- Instruction card in admin shows how to add Drive video links
