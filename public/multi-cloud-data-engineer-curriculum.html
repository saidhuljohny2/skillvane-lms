Structured curriculum

01 · Cloud Computing Foundations

  • What cloud computing is and why businesses moved to cloud
  • Cloud service providers: GCP, Azure, AWS
  • Data Lake, Data Warehouse, and Lakehouse mental models

02 · GCP Platform, IAM & Linux

  • Console, Cloud Shell, Cloud SDK, regions, zones, projects, folders, billing
  • IAM: principals, roles, service accounts, resource hierarchy
  • Free account setup plus Linux files, permissions, grep, awk, sed

03 · Python for Data Engineers

  • Types, structures, control flow, functions, classes, modules, packaging
  • File I/O, exceptions, logging, datetime, REST APIs with requests

04 · Google Cloud Storage

  • Buckets, objects, IAM, lifecycle, versioning, transfer, monitoring
  • Labs on console and CLI: create, upload, download, permissions

05 · Cloud SQL & Database Migration

  • Instances, users, HA, backups, Studio/Shell/workbench connectivity
  • Project: manual export/import vs automated Cloud SQL DMS

06 · BigQuery SQL & Analytics

  • Architecture, slots, nested JSON, native vs external tables, views
  • Load/export/stream, optimization, Spotify and social-media case studies

07 · Dataproc & PySpark

  • Managed Spark clusters, preemptible cost control, job debugging
  • Read/transform/write files, SQL, and BigQuery; 3 PySpark case studies

08 · Dataflow, Apache Beam & Pub/Sub

  • Beam vs Spark, Dataflow vs Dataproc, topics/subscriptions/acks
  • Templates, e-commerce processing, end-to-end streaming pipeline

09 · Cloud Composer (Airflow DAGs)

  • Environment setup, retries, logging, BigQuery / Dataproc / Dataflow DAGs
  • CI/CD for DAGs using Cloud Build and GitHub

10 · Azure Foundations & ADLS Gen2

  • Subscriptions, resource groups, IAM, free account, ADLS hierarchy
  • RBAC vs ACLs, Hot/Cool/Archive tiers, portal/CLI/SDK/REST access

11 · Azure SQL, Data Factory & Synapse

  • ADF pipelines, IR, datasets, triggers, monitoring, and parallelism
  • Incremental ADF + ADLS + SQL case study; Synapse pools and lake SQL

12 · Databricks Lakehouse (Azure / GCP)

  • Workspace, clusters, Unity Catalog, Delta Lake ACID and incremental ELT
  • Structured Streaming and Autoloader case studies; performance tuning
